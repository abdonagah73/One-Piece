# ⚓ One Piece V3 — سفينة الاختصارات والإنتاجية الذكية

![One Piece App Preview](assets/images/app_preview.png)

تطبيق ويب متكامل يعمل بنظام **Offline-First (100% محلياً وبدون أي سيرفر خارجي)** لتنظيم وإدارة جميع روابطك ومواقعك اليومية، مع حزمة متكاملة من أدوات الإنتاجية والتركيز بتصميم زجاجي داكن عصري (**Modern Dark Glassmorphism & Bento UI - Electric Cobalt**).

---

## ✨ أبرز مميزات الإصدار الثالث (One Piece V3)

### 🎨 1. واجهة زجاجية عصرية وتجاوب كامل (Responsive Bento UI)
- **نظام التصميم الكهربائي الداكن (`Electric Cobalt`)**: واجهة زجاجية (`Glassmorphism`) مريحة للعين مع إضاءة محيطية ناعمة (`Ambient Glows`) وكروت `Bento` تفاعلية.
- **تجاوب شامل للموبايل والتابلت والكمبيوتر (`Mobile-First Responsive`)**:
  - قائمة جانبية منزلقة مخصصة للهواتف (`Slide-over Mobile Sidebar`) مع طبقة تعتيم ضبابية وإغلاق تلقائي ذكي عند اختيار التصنيف.
  - شريط علوي مرن مع تمرير أفقي سلس لمحركات البحث السريعة على الشاشات الصغيرة.
  - توافق كامل لأنماط العرض الثلاثة (**الشبكي `Grid`**، **القائمة `List`**، و**دفتر الليدجر `Ledger`**) والنوافذ المنبثقة على جميع مقاسات الشاشات.
- **4 هويات وشخصيات للتطبيق**: (`ون بيس 🏴‍☠️`، `إنتاجي Pro 💼`، `سايبربانك ⚡`، `هدوء Zen 🍃`).

### 🔍 2. البحث الذكي ولوحة الأوامر السريعة
- **البحث المحلي الفوري (`Omni-Search`)**: ابحث فوراً في عناوين الروابط، النطاقات، الأوصاف، أو الوسوم (`#Tags`) بالضغط على `/`.
- **البحث الخارجي المباشر**: أزرار سريعة للبحث المباشر في `Google`، `YouTube`، `ChatGPT`، و `GitHub`.
- **لوحة الأوامر السريعة (`Command Palette - Ctrl + K`)**: تنفيذ الأوامر والوصول لأي رابط أو أداة بسرعة فائقة عبر الكيبورد.

### ⚡ 3. الرصيف الجانبي للإنتاجية (`Productivity Hub`)
- **مؤقت بومودورو (`Pomodoro Timer`)**: أوضاع تركيز (`25د`) واستراحة قصيرة (`5د`) وطويلة (`15د`) مع حلقة تقدم `SVG` وتنبيه صوتي مُولّد عبر `Web Audio API` بدون أي ملفات صوتية خارجية.
- **قائمة مهام اليوم (`Daily Todos`)**: إضافة وإنجاز المهام اليومية مع عداد للمهام المتبقية وحفظ تلقائي.
- **المفكرة السريعة (`Quick Scratchpad`)**: مساحة كتابة فورية للملاحظات والأفكار والأكواد مع حساب عدد الكلمات والأحرف ونسخ بضغطة زر.

### 🛠️ 4. إدارة متقدمة للروابط والتصنيفات
- **تثبيت الروابط المهمة (`Pinned Favorites ⭐`)**: شريط وصول سريع في أعلى الصفحة مع دعم الفتح السريع بالأرقام (`1 - 9`).
- **ترتيب مخصص بالسحب والإفلات (`Drag & Drop`)**: إعادة ترتيب الكروت أو سحب أي رابط وإفلاته داخل تصنيف آخر في القائمة الجانبية، بالإضافة للفرز حسب (الأكثر استخداماً، الأحدث، أبجدياً).
- **معاينة الرابط السريعة (`Quick Peek 👁️`)**: عرض تفاصيل الرابط، حالة التشفير `HTTPS`، الوسوم، وإحصائيات النقرات في نافذة سريعة.
- **خزانة قراءة لاحقاً (`Read Later Shelf 🔖`)**: حفظ المقالات والروابط لقراءتها لاحقاً مع تقدير وقت القراءة.
- **فاحص سلامة الروابط المباشر (`Live Link Health Checker ❤️‍🩹`)**: فحص اتصال جميع الروابط المحفوظة والتأكد من عملها.
- **مولد رمز الاستجابة السريعة (`QR Code 📱`)**: مشاركة أي رابط فوراً إلى هاتفك عبر مسح رمز `QR`.
- **سلة المهملات والاسترجاع الفوري (`Trash Bin & Undo 🗑️`)**: إمكانية التراجع الفوري (`Undo`) عند حذف أي رابط أو استعادته من سلة المهملات.

### 📊 5. لوحة الإحصائيات والنسخ الاحتياطي
- **مركز التحليلات ونظام الرتب (`Analytics & Rank System`)**: متابعة إجمالي الروابط والزيارات، أعلى 5 مواقع زيارة، توزيع الروابط على التصنيفات، وترقية رتبتك من *ملاح متدرب 🧭* إلى *قبطان الأسطول 👑*.
- **تصدير واستيراد شامل**:
  - نسخ احتياطي واستعادة كاملة بصيغة `JSON` (مع خيار الدمج `Merge` أو الاستبدال `Replace`).
  - استيراد وتصدير ملفات إشارات المتصفح القياسية (`Bookmarks HTML`) المتوافقة مع `Chrome` و `Edge` و `Firefox`.

## ⌨️ اختصارات لوحة المفاتيح (`Speed Navigator`)

| الاختصار | الوظيفة |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | فتح لوحة الأوامر السريعة الشاملة (`Command Palette`) |
| <kbd>/</kbd> | التركيز الفوري في شريط البحث الرئيسي |
| <kbd>?</kbd> | فتح دليل اختصارات لوحة المفاتيح |
| <kbd>1</kbd> - <kbd>9</kbd> | فتح الرابط المثبت المقابل في قسم المفضلة فوراً |
| <kbd>J</kbd> / <kbd>K</kbd> أو الأسهم | التنقل السريع بين كروت الروابط |
| <kbd>Enter</kbd> | فتح الرابط المحدد حالياً |
| <kbd>Z</kbd> | تفعيل / إيقاف وضع التركيز الفائق (`Zen Mode`) |
| <kbd>Esc</kbd> | إغلاق أي نافذة منبثقة أو القائمة الجانبية |

## 🔒 الأمان والخصوصية (`Offline-First`)
- يعمل التطبيق بنسبة **100% محلياً على جهازك** بدون الحاجة لأي خادم خارجي أو قاعدة بيانات سحابية.
- تُحفظ جميع الروابط، التصنيفات، المهام، والملاحظات داخل متصفحك عبر `localStorage` مع خصوصية تامة.
