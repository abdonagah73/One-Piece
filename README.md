# ⚡ One Piece Application Core - الدليل التقني الداخلي

هذا المجلد يحتوي على كود المصدر الأساسي لتطبيق **One Piece Bookmarks Hub & Productivity Fleet**.

---

## 📂 بنية المجلد الداخلي (`/app`)
- **`index.html`**: واجهة المستخدم الرئيسية المكتوبة بـ HTML5 الدلالي مع دعم كامل لنظام الكتابة من اليمين إلى اليسار (`dir="rtl"`).
- **`assets/css/style.css`**: ملف التنسيق الموحد الذي يشمل:
  - نظام الألوان النيوبروتاليستي والـ Design Tokens.
  - استوديو الأنماط البصرية الأربعة (`Sunny`, `Cobalt`, `Editorial`, `Noir`).
  - شبكة الكروت المتجاوبة بالكامل عبر الـ Auto-fill و Breakpoints.
  - الرصيف الجانبي للإنتاجية ولوحة الأوامر السريعة.
- **`assets/js/app.js`**: ملف الجافاسكريبت الأساسي الذي يدير:
  - محرك البحث الذكي `Omni-Search`.
  - لوحة الأوامر السريعة (`Ctrl + K`).
  - مؤقت بومودورو للتركيز المعتمد على Web Audio API بدون ملفات صوتية خارجية.
  - قائمة المهام اليومية والمفكرة السريعة مع الحفظ التلقائي في LocalStorage.
  - مولد أكواد الـ QR للموبايل.
  - الترتيب بالسحب والإفلات وحفظ الترتيب المخصص.
  - تصدير واستيراد ملفات النسخ الاحتياطي بتنسيق JSON.
- **`assets/images/logo.png`**: شعار ون بيس الأصفر الرسمي.
- **`assets/icons/logo.ico`**: ملف Favicon وأيقونة سطح المكتب متعددة المقاسات.

---

## 🔒 الأمان والخصوصية (Offline-First)
- التطبيق يعمل بنسبة 100% بدون أي سيرفر خارجي.
- جميع بيانات الروابط، التصنيفات، المهام، والملاحظات مخزنة محلياً في متصفحك عبر `localStorage`.
- لا يتم إرسال أي بيانات أو تتبع لأي طرف ثالث.
